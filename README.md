# ShelfMate

A small reading tracker: keep a shelf of the books you want to read, are reading and have finished.

## Features

- **Accounts:** sign up with an email and a password, sign in and sign out. Each reader sees only their own shelf.
- **Books:** add, edit, search and delete books, mark them Want to read, Reading or Finished, and rate finished books from 1 to 5.
- **Export and goal:** export the whole shelf as a CSV file, and set a yearly reading goal with a progress bar.

Run it locally with `npm install` then `npm start`, and open http://localhost:3000.
