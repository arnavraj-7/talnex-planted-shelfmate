# ShelfMate

A small reading tracker.

## Features

- **Books:** add, edit, search and delete books, and filter the shelf by Want to read, Reading or Finished.
- **Ratings:** rate finished books from 1 to 5 and see the average rating.
- **Export and goal:** export the whole shelf as a CSV file, and set a yearly reading goal with a progress bar.

Static site: open `public/index.html`, or deploy the folder to Vercel.
